# Project Overview

## Purpose

This project is a single-page portfolio site built with React and TypeScript. It presents a professional profile, work history, projects, education, certificates, and contact details with a themed UI and lightweight interactions.

## Tech Stack

- React 18 (Create React App)
- TypeScript
- React-Bootstrap + Bootstrap
- Sass (SCSS)
- Font Awesome (icons)
- React-Toastify (notifications)
- EmailJS (anonymous feedback email delivery)

## Entry Points

- App bootstrap: src/index.tsx
- App shell: src/App.tsx
- Primary page: src/pages/Home.tsx
