# Features

## Content Sections

- Introduction with profile image and summary.
- Work history with project responsibilities and technologies.
- Projects gallery with descriptions and tech badges.
- Education timeline.
- Certificates list with per-item detail cards.
- Contact section with links and direct contact details.

## Theme Support

- Light, dark, and system theme modes.
- Theme preference stored in localStorage.
- CSS variables swap based on the data-theme attribute.

## Anonymous Feedback

- EmailJS-backed form to send feedback without exposing credentials.
- Global spinner while sending.
- Toast notifications for success or error.
- Tooltip prompt to explain feedback purpose.

## Utilities

- Date formatting utility for certificate ordering and display.
- Reusable tooltip wrapper for consistent overlays.
